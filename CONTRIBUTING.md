# Contributing to WaveLab

A useful example makes one behavior easy to see. Keep the setup short, use fictional data, and explain what the reader should notice.

For a fix, include the command that reproduces the problem. For a new demo, add it under `demos/`, document the expected output, and link it from the root README.

Before opening a pull request, run `npm run check`. If your example calls a model, also provide a way to explore the core behavior without a paid API call. Label recorded or scripted output clearly.
